# Política de seguridad

## Reportar un problema

Si encuentra en este repositorio un guion que puede dañar un equipo, un indicador equivocado que bloquearía servicios
legítimos o cualquier otro problema de seguridad, escriba a contacto@cutsecurity.cl con el asunto «Respuesta rápida».
No abra un issue público para un problema que pueda aprovecharse.

Respondemos en días hábiles. Si confirmamos el problema, corregimos el kit, publicamos una versión nueva y lo
anotamos en el CHANGELOG.

## Qué no publicamos

- Código de explotación ni pruebas de concepto ofensivas.
- Datos de clientes, nombres de personas ni claves.
- Indicadores sin una fuente que los respalde.
